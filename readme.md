# Парсер договоров

Веб?приложение для автоматического извлечения ключевых данных из договоров в форматах PDF, DOCX, DOC и TXT.

## Возможности

* Извлечение данных из файлов форматов: PDF, DOCX, DOC, TXT.
* Автоматическое распознавание реквизитов (ИНН, КПП, ОГРН, ОКПО, банковские реквизиты).
* Извлечение финансовой информации (сумма договора, НДС, условия оплаты).
* Определение сторон договора (поставщик, покупатель) и их представителей.
* Поиск контактных данных (телефоны, email).
* Распознавание дат, номеров и типов договоров.
* Анализ сроков действия и условий поставки.
* Отслеживание пропущенных обязательных полей.
* Расчёт полноты заполнения данных (в %).
* Ведение истории обработанных документов.
* Веб?интерфейс для загрузки файлов и просмотра результатов.
* Возможность скачивания результатов в формате JSON.

## Технологии

* **Python 3.x** — основной язык программирования.
* **Flask** — веб?фреймворк.
* **pdfplumber** — извлечение текста из PDF.
* **python-docx** — работа с документами DOCX.
* **win32com** — работа с документами DOC через COM?интерфейс Word (только Windows).
* **re** — регулярные выражения для поиска данных по шаблонам.
* **json** — формат хранения результатов и истории.
